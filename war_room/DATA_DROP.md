Overview
This project is completed on an external platform that requires you to use a Google Workspace account - please refer to this document for guidance on how to set up / access your Google Workspace credentials.

Review the workflow below to understand when you should be submitting tasks on the DataAnnotation platform for this project.

Workflow
Follow the link below to access the external platform and start a work session.

Within the external platform's session you will be asked to complete one or more tasks.

⚠️ If you do not have the topic/domain expertise to complete the task you are shown, please skip it! Skipping does not count against you.

Before submitting your task on DataAnnotation, you must end your session on the external platform by clicking the stop button on the top right. Sometimes your session on the external platform will be ended automatically after you submit a task.

If you see a "The current session is complete" message on the external platform, that means your session was ended automatically.

Only after your session has ended (either by you or automatically), complete any remaining items on the DataAnnotation task and submit it.

Note that in this project, it's fine to go past the time limit in the DataAnnotation task and submit it after expiration.

IMPORTANT: do not bookmark or reuse links to the external platform. Each link is specific to a single DataAnnotation task.


FAQ for this project family
Q: I'm getting "Error: You need to enable popups in the URL bar and refresh the page!" when I open the external platform. What should I do?

A: Enable popups through the URL bar of your browser and refresh the page. You will be authenticating on the external platform through your Google Workspace account described in the project instructions above, and if popups are disabled, the authentication popup will be suppressed.

Q: What should I do if one or both app previews are blank?

A: Make sure that the previews aren't just still loading. If there's no indication they're still loading, then you can report the task with the "I am unable to proceed because the responses are stuck and/or in an invalid state." option.

Q: What should I do if one or both responses have blank code?

A: If the task instructions on the external platform only ask you to evaluate dimensions that don't require the code to be evaluated, this is fine. In some projects, the raw code has not been included in the task, just the app preview. Examples of dimensions that don't require the code to be evaluated include visual quality and UI/UX quality. If the task does ask you to evaluate something that requires the code and the code is missing, you can report the task with the "I am unable to proceed because the responses are stuck and/or in an invalid state." option.

Q: What should I do if the prompt is not in English?

A: In this project, you can use Google Translate to help translate the prompt and any part of the response, since typically, the dimension that you are rating can still be evaluated without having native understanding of the non-English prompt. If there is too much non-English text to easily understand the prompt or evaluate the responses, you can report the task with the "Other" option, with a brief explanation.

Q: What should I do if the app preview is showing a build error or compile error?

A: If the code is shown and you are equipped to do so, try to build the app locally (including any missing dependencies) and evaluate. Leave a note in your explanation about the error and saying you had to build the app locally. If you don't know how to build the app locally, skip the task.

Q: The external platform is saying that there are no more tasks available. What do I do?

A: Take this at face value; the project most likely has no more tasks available. The DA project should be paused and hidden at some point after this happens by the project requester, but this doesn't happen immediately since people working on the last tasks may abandon them.

IMPORTANT
Please make sure that you read the task instructions and questions on the external platform carefully once you open it. We have had issues in previous projects where people have not been following the task instructions. In particular, if the instructions tell you to rate a response only based on certain criteria, stick to just assessing those criteria, and do not take other criteria into consideration. For example, if the task instructions tell you to specifically rate based on the visual quality of a web app, do not factor in other dimensions like code quality or functionality.
