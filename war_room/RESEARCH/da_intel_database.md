## 6. KEY WORKER INTELLIGENCE

### Performance Feedback System
- DA sends feedback emails (possibly monthly/end-of-month)
- Includes ratings: Outstanding, Good, Needs Improvement
- Provides specific examples from your work
- Shows where you need to improve
- Getting feedback = your account is active and being reviewed (GOOD sign)

### The 10-Hour Clock Projects
- Some projects give 10-hour timers (vs typical 2-hour)
- No official pause mechanism — you work within the window
- Workers use "exit work mode" and return to the project

### Escape Hatch
- When submit button errors out, workers use "escape hatch" to exit
- This is a known UI bug, not a worker error
- You still bill for time worked even if you escape hatch

### Report Time Tab
- Red notification = time entries need attention
- NOT a punishment — just administrative
- Can be triggered by edits, new submissions, or system flags
