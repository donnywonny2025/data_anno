# Circe / Flamingo — Rules
Pay: Credential unlock (no direct pay) | Unlocks: Flamingo visual project family
Completed: May 1, 2026

## What This Is
Circe is a one-time credential delivery system. It grants temporary access to a shared "Flamingo" Google account used for visual evaluation projects.

## How Flamingo Projects Work
1. A Flamingo project appears on the dashboard (will have "Flamingo" in the name)
2. Open the **Account Credentials project** (second version of Circe, long timer) to see the login credentials
3. Go to google.com and log into the Custom Account with those credentials
4. **Exit work mode** on the Account Credentials project
5. Go work on the actual Flamingo project

## Critical Rules — NON-NEGOTIABLE
- ❌ Do NOT change the account's password or name
- ❌ Do NOT attach a phone number or email address to the account (including for authentication)
- ❌ Do NOT screenshot or copy-paste credentials off-platform (no notepad, no notes app)
- ❌ Do NOT use Flamingo credentials for any project that does NOT have "Flamingo" in the name
- ✅ Triple-check you're using the correct credentials before starting
- ✅ The account is shared — other workers use it too
- ⚠️ Violating these rules = exclusion from all credential projects in the future

## Workflow for Future Flamingo Tasks
